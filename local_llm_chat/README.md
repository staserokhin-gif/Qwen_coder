# Локальный AI-чат на Streamlit + Bionic

Веб-приложение на Python/Streamlit с интерфейсом чата для общения с локальной
LLM, развернутой на сервере **Bionic** (OpenAI-совместимый REST API).

## Возможности

- Потоковая передача ответов модели (`st.write_stream`, `stream=True`).
- Динамический выбор модели — список подгружается с Bionic при старте.
- Настройка температуры и системного промпта в боковой панели.
- Управление историей диалога через `st.session_state` + кнопка «Очистить историю».
- Корректная обработка недоступного сервера и обрыва генерации.

## Структура проекта

```text

├── requirements.txt    # Зависимости проекта
├── .env.example        # Пример настроек окружения
└── README.md           # Этот файл
```

## Пререквизиты

1. **Python 3.12**.
2. Установленный и **запущенный локально сервер Bionic**, экспортирующий
   OpenAI-совместимый endpoint по адресу `http://localhost:1235/v1`.

   Установка (через pip):

   ```bash
   pip install bionic
   ```

   Запуск сервера (по умолчанию слушает порт `1235`):

   ```bash
   bionic serve
   ```

   Загрузка тестовой модели (например, TinyLlama):

   ```bash
   bionic pull tinyllama
   ```

   Проверка доступности endpoint:

   ```bash
   curl http://localhost:1235/v1/models
   ```

```bash
cd local_llm_chat

```

## Настройка переменных окружения

По умолчанию приложение обращается к `http://localhost:1235/v1`. Чтобы указать
другой адрес, задайте переменную окружения `BIONIC_BASE_URL` (см. `.env.example`):

```bash
# Linux / macOS
export BIONIC_BASE_URL="http://localhost:1235/v1"

# Windows (PowerShell)
$env:BIONIC_BASE_URL = "http://localhost:1235/v1"
```

API-ключ не требуется: Bionic не выполняет авторизацию, клиент использует
заглушку `"not-needed"` (задана в `config.py`, реально секреты не хранятся).

## Запуск

Сначала убедитесь, что Bionic запущен, затем:

```bash
streamlit run app.py
```

Откроется интерфейс чата в браузере (по умолчанию `http://localhost:8501`).

## Решение проблем

| Симптом | Причина / решение |
|---|---|
| «Не удалось подключиться к серверу Bionic...» | Сервер не запущен или URL неверен — проверьте `bionic serve` и `BIONIC_BASE_URL`. |
| Пустой список моделей | К Bionic не загружена ни одна модель — выполните `bionic pull <модель>`. |
| Ответ обрывается посередине | Соединение со стримом прервалось; частичный ответ сохраняется в истории, UI показывает ошибку и продолжает работать. |
